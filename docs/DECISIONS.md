# Decisions

## Foundation

- Target .NET 10, the installed current LTS, which satisfies the brief's .NET 8 or newer LTS requirement.
- Use the .NET 10 solution format (`.slnx`) generated by the installed SDK.
- Keep the MVP deployable as one ASP.NET Core API and one Blazor web app; PostgreSQL is the shared datastore.
- Serilog writes structured events to console and rolling local files. Production log retention and external aggregation remain deployment configuration.
- Readiness checks PostgreSQL connectivity; liveness only checks that the API process responds.
- The initial compose password is for local development only. Set `POSTGRES_PASSWORD` outside local development.

## Package choices

- `Npgsql.EntityFrameworkCore.PostgreSQL` provides EF Core's PostgreSQL provider and database connectivity required by the architecture.
- `Serilog.AspNetCore` integrates request and application logging; `Serilog.Sinks.File` adds the requested rolling local log output alongside console output.
- `Microsoft.Extensions.Diagnostics.HealthChecks` supplies the health check interfaces and registration used for PostgreSQL readiness.
